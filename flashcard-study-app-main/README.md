# Study Master — Unternehmensformen

Новая реализация по приложенному HTML-шаблону Vocab Master: белые карточки, фиолетовые акценты, вкладки, счётчики, дневная цель и сохранение прогресса. Прежнее приложение и его код удалены из текущей версии; предыдущие версии доступны в истории Git.

## Учебный материал

117 ответов (13 форм × 9 критериев) извлечены из приложенного пользователем текста. Формулировки сохранены без добавления внешних учебных сведений. Исходные сокращённые записи и словарь доступны в справочнике. Содержимое английского демонстрационного шаблона не включено.

- `data/source.md` — приложенный учебный текст.
- `data/study.json` — структурированные данные; `data.js` — те же данные для автономного открытия страницы.
- `docs/sources/` — две исходные фотографии.

## Работа

Откройте `index.html` или выполните `npm start` (Python 3). Установка зависимостей для самого сайта не требуется. Внешних шрифтов, сервисов и API нет; распакованный проект работает без сети.

- **Karteikarten:** показать полный ответ, оценить себя, повторить ошибки.
- **Multiple Choice:** выбрать ответ среди уникальных альтернатив того же критерия.
- **Match:** сопоставить вопросы и ответы; одинаковые/эквивалентные ответы не попадают в одно поле.
- **Speed Round:** верно/неверно за 60 секунд; пауза вручную, при уходе со вкладки или смене раздела.
- **Nachschlagen:** все формулировки, поиск, фильтры и исходные записи.

Фильтры действуют на все разделы. Выбор новой формы или критерия начинает новую тренировку. Варианты ответа могут использовать другие формы из полного набора. Прогресс хранится только в этом браузере под новым ключом `unternehmensformen-template-v1`; старый прогресс не смешивается с новым. «Sicher» означает две последние правильные оценки подряд, включая самооценку по карточкам. Повторение после правильных ответов — через 1, 3, 7 и 14 дней. Ошибки доступны для повторения сразу. При недоступном хранилище тренировка продолжает работать в памяти.

## Проверка

Для автоматических тестов требуется Node.js, совместимый с jsdom 31:

```sh
npm ci
npm test
```

9 тестов прошли: полнота данных; все 117 карточек и защита от повторной оценки; фильтры и справочник; все 117 вопросов Multiple Choice; ошибочные ответы; все 117 пар Match; повторы и одна пара; пауза/истечение времени Speed Round; сохранение, сброс и повреждённое хранилище.

В браузере проверены все четыре режима, обратная связь, длинный ответ GbR, узкие размеры окна 320/393 px и настольный 1366 px. Переполнения карточки и страницы не обнаружено. Ошибок JavaScript в журнале браузера не обнаружено. На физическом iPhone/Safari тест не выполнялся.
