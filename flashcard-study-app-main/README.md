# Study Desk · Unternehmensformen

Готовая адаптация исходного проекта `flashcard-study-app-main` по двум фотографиям таблиц **Unternehmensformen im Überblick – Grundlage für die Eröffnung von Firmenkonten**.

**13 форм × 9 критериев = 117 карточек только по двум предоставленным фотографиям**, доступных во всех четырёх режимах. Учебный материал — на немецком; названия режимов и основные элементы интерфейса сохранены на английском, как в исходном проекте и образце. Оформление сохраняет бумагу в клетку, пастельные стикеры, декоративный скотч и исходное расположение режимов.

## Запуск

1. Распакуйте архив целиком.
2. Откройте `index.html` двойным щелчком. Сборка, установка библиотек и учётная запись не нужны.
3. Выберите режим, сложность, формы/критерии и нажмите **Start studying**.

Данные и игровая логика работают без интернета. При доступе к сети исходные шрифты загружаются из Google Fonts; без сети используется системный шрифт. 

Для сохранения прогресса в файл, а не только в браузер:

```sh
python3 server.py
```

В Windows можно использовать `py server.py`. В macOS сохранён исходный `Open Flashcards.command`. Сервер печатает адрес, обычно `http://127.0.0.1:4450`, и записывает `progress.json` рядом с проектом. Остановка — Ctrl+C. Без сервера доступность сохранения зависит от настроек хранения браузера; для переноса есть Copy/Load save data.

## Четыре режима

| Режим | Работа |
|---|---|
| Flashcards | Форма и критерий на лицевой стороне, полный ответ по таблице на обороте. Оценка доступна после переворота. Study again / Got it, отметка сложных карточек. В Hard — автоматический переворот через 12 секунд. |
| Match | Сопоставление вопросов с полными ответами. До 4/6/8 пар на поле; повторяющиеся и близкие ответы разнесены по разным полям. Весь выбранный набор проходится без потерь и добавления посторонних карточек. |
| Multiple choice | До 3/4/5 вариантов по одному критерию. 30/20/12 секунд на вопрос; неограниченное число / 3 / 2 жизни. Полные варианты, обратная связь, явная кнопка Next. Число вариантов сокращается, если нет достаточного числа однозначных альтернатив. |
| Speed round | Верно или неверно для пары «форма + критерий / ответ». 90/60/45 секунд; штраф за ошибку 0/3/5 секунд. Правильный ответ после ошибки, очки и серии ответов. |

Во всех режимах: пауза, завершение с результатами, повтор игры и повтор ошибок как карточек. При уходе с вкладки игра ставится на паузу. Правильные ответы пополняют изученные карточки; ошибки сохраняются для повторения. Ошибка в рамках текущего раунда остаётся в списке повторения даже после последующего правильного ответа.

Горячие клавиши: Space — переворот, 1/2 — оценка карточки, 1–5 — варианты теста, F/J или стрелки — False/True, S — сложная карточка, Esc — пауза.

## Выбор материала и таблицы

- **Forms & criteria**: нажатие названия пересекает фильтры; `+` объединяет наборы; `−` исключает карточки.
- Для более простого выбора раскройте **Source tables**, выберите форму и критерий и нажмите **Use this selection**.
- Вопросы соответствуют выбору. Неверные варианты для тестов берутся по тому же критерию из полной базы, чтобы работал даже выбор одной карточки.
- **Show source wording** показывает исходные формулировки, включая ссылки «wie GmbH/KG». В учебном варианте такие ссылки раскрыты по тем же таблицам.
- **Browse all cards**: поиск, отметки сложных карточек, теги и экспорт для Quizlet/Anki.

## Полнота и проверка содержания

Первая таблица: Einzelunternehmen, GbR/BGB-Gesellschaft, OHG, KG, Partnerschaftsgesellschaft, e. V. Вторая: GmbH, AG, UG (haftungsbeschränkt), SE, GmbH & Co. KG, KGaA, Genossenschaft/eG.

Для каждой формы перенесены все девять строк: общие признаки и правовая основа; учреждение; минимальный капитал; управление; представительство; удостоверение личности/название/реестр; органы; ответственность; распределение прибыли.

Учебная база содержит только материал первых двух фотографий. Прежние карточки, примеры и скриншот старого курса удалены. Никакие дополнительные правовые правила из внешних источников в задания не включены.

Все пункты двух таблиц сохранены. Сокращения раскрыты, разорванные переносами слова соединены. Ссылки «wie GmbH/KG» раскрыты по содержанию тех же фотографий. Ответы оцениваются именно на соответствие предоставленным таблицам; их спорные или упрощённые формулировки не подменены другими сведениями.

[Покрытие содержания](docs/CONTENT_COVERAGE.md) перечисляет все формы и критерии. Обе исходные фотографии сохранены в проекте.

## Структура

```text
index.html, styles.css, app.js    исходная структура и доработанные режимы
question-engine.js               однозначные варианты и поля Match
reference.js                     просмотр и фильтрация таблиц
cards.csv                        117 карточек для импорта/редактирования
cards-builtin.js                 автономная копия CSV
study-data.js                    автономные исходные данные таблиц
data/unternehmensformen.json     полная матрица 13 × 9 из фотографий
tools/generate_deck.py           пересборка CSV и JS из матрицы
server.py                       исходный локальный сервер сохранений
tests/                          тесты данных, логики и DOM
docs/sources/                   обе фотографии и визуальный образец
docs/CONTENT_COVERAGE.md         полнота переноса фотографий
docs/QA.md                      результаты проверок и ограничения
```

Для редактирования учебного содержания предпочтительно менять JSON, затем запускать `python3 tools/generate_deck.py`: это синхронизирует карточки, справочные таблицы и группировку равнозначных ответов. `server.py` также сохраняет исходную возможность обновлять автономную копию из `cards.csv`; ручное изменение CSV не обновляет справочные таблицы и группы равнозначности в JSON.

## Тестирование разработчиком

Для запуска самого приложения Node.js не нужен. Для тестов требуется Node.js 22.12+:

```sh
npm install
npm test
```

Тесты не открывают браузер и не выполняют сетевые запросы. DOM-проверки не подтверждают реальную отрисовку CSS. В этой сессии браузерный предпросмотр был отклонён системой разрешений; визуальная проверка и проверка на реальном телефоне не выполнены. Подробности — [QA](docs/QA.md).
