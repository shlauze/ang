# Study Master — Unternehmensformen

Тренажёр в оформлении приложенного шаблона с двумя вкладками.

- **Karteikarten:** кнопки Alle 1–6. Первые пять частей содержат по 20 карточек, шестая — 17. Вопрос, полный ответ по нажатию, самооценка, счётчики и повторение ошибок.
- **Match:** сопоставить вопрос с одним из трёх ответов. 12 частей: первые 11 по 10 заданий, последняя — 7. Альтернативы взяты из того же критерия; одинаковые и эквивалентные ответы исключены. После выбора показаны правильный ответ и кнопка Weiter.

Состав частей фиксирован и покрывает все 117 вопросов без пропусков и повторов. Порядок внутри части перемешивается. В конце можно повторить ошибки, пройти часть заново или открыть следующую. Переключение вкладок сохраняет незавершённый раунд в памяти до перезагрузки страницы. Записи об ответах сохраняются в браузере.

Содержание: 13 форм предприятий × 9 критериев, только из приложенных пользователем данных. Исходный текст — `data/source.md`, структурированные данные — `data/study.json` и `data.js`. Две исходные фотографии — `docs/sources/`.

Откройте `index.html` или выполните `npm start` (Python 3). Сайт работает без внешних сервисов.

Для проверок: `npm ci`, затем `npm test`. Требуется Node.js, совместимый с jsdom 31. Четыре теста проверяют все 117 карточек в шести частях; все 117 вопросов Match с тремя уникальными вариантами; повторы ошибок, навигацию и переключение вкладок; сохранность материала и обработку повреждённого хранилища. Также выполнена браузерная проверка узкого экрана и обратной связи Match. Физический iPhone не использовался.

Корневая папка Vercel: `flashcard-study-app-main`, сборка не требуется. MIT-лицензия сохранена.
