# Study Master — Unternehmensformen

Простой тренажёр карточек в оформлении приложенного шаблона. Один экран: вопрос, полный ответ по нажатию, самооценка «Gewusst / Noch unsicher», счётчики и итог раунда. После завершения можно повторить ошибки или начать новый раунд из всех 117 карточек. Выбор тем, фильтры, поиск, справочник и другие виды заданий удалены.

Содержание: 13 форм предприятий × 9 критериев, только из приложенных пользователем данных. Исходный текст находится в `data/source.md`, структурированные данные — в `data/study.json` и `data.js`. Две исходные фотографии сохранены в `docs/sources/`.

Откройте `index.html` или выполните `npm start` (Python 3). Сайт работает без внешних сервисов. Прогресс сохраняется в этом браузере; кнопка «Neue Runde» начинает новый раунд, сохраняя накопленные записи. Если хранилище недоступно, тренажёр продолжает работать до закрытия страницы.

Для проверок: `npm ci`, затем `npm test`. Проверяются полнота 117 ответов, отсутствие выбора тем и режимов, полный раунд, повторение ошибок, защита от повторной оценки и сохранение. Для запуска тестов нужен Node.js, совместимый с jsdom 31.

Корневая папка Vercel: `flashcard-study-app-main`, сборка не требуется. MIT-лицензия сохранена.
